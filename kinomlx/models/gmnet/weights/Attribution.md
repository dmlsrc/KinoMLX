# Attribution

[`kinomlx/models/gmnet/`](../) is an independent MLX reimplementation of
the GMNet inverse-tone-mapping generator, written from the published
architecture as a specification - no upstream code is bundled. The model
weights are the upstream project's, converted 1:1 from its published
checkpoints (see [README.md](README.md) beside this file for the
downloads).
